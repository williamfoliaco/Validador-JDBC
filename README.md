# Validador JDBC  EA3

## Descripcion
Aplicacion de escritorio desarrollada en Java Swing para configurar y validar conexiones a bases de datos mediante JDBC.

## Tecnologias
- Java JDK 17
- Java Swing
- JDBC
- H2 Database Engine
- Maven
- NetBeans

## Configuracion JDBC

- Driver: org.h2.Driver
- URL: jdbc:h2:mem:prueba
- Usuario: sa
- Contrasena: vacia

## Ejecucion
Abrir el proyecto Maven en NetBeans, esperar la descarga de las dependencias y ejecutar la clase ValidadorJDBC.

## Funcionamiento
La aplicacion permite ingresar los parametros de conexion, probar la conexion y mostrar mensajes de exito o errores JDBC.
